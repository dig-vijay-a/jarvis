# NOVA Operating System — User Guide

Welcome to NOVA, your personal AI command center inspired by Tony Stark's JARVIS.

---

## 1. Quick Navigation Shortcuts

Use standard keyboard numbers `1` through `7` from any screen to navigate:

| Key | Section | Description |
|---|---|---|
| `1` | **Command HUD** | Central dashboard with Arc Reactor, Waveforms, Status, Quick Actions. |
| `2` | **Neural Chat** | Full terminal chat interface with tool call execution details. |
| `3` | **Memory Banks** | Long-term memory manager with taxonomy filters and search. |
| `4` | **Workflows** | Autonomous multi-step agent pipelines (YouTube, Briefings). |
| `5` | **Computer Link** | Hardware monitor, permitted application launcher, and file explorer. |
| `6` | **Web Research** | Deep web search and intelligence report generator. |
| `7` | **Core Settings** | API keys, model selection, TTS pitch/rate, and security tokens. |

---

## 2. Voice Directives

Click the central Arc Reactor or press the Microphone button to begin speaking.

### Computer Control Examples:
- *"Hey Nova, open VS Code."* -> Launches Visual Studio Code.
- *"Open Chrome."* -> Launches Google Chrome browser.
- *"Open Calculator."* -> Launches Windows Calculator.
- *"Go to github.com."* -> Opens GitHub in your default browser.
- *"Search files for package."* -> Locates matching project files.

### Productivity & Planning:
- *"What should I work on today?"* -> Reads your active tasks and priority items.
- *"Remind me to study React at 8 PM."* -> Schedules an audio-visual reminder.
- *"Start a 45-minute focus session."* -> Initiates deep work countdown timer.
- *"Add task: Refactor AI orchestrator."* -> Adds new item to your task register.

### Autonomous Workflows:
- *"Prepare my YouTube content for today."* -> Researches AI trends, outlines video script, generates viral Shorts script, and archives output.
- *"Prepare my daily executive briefing."* -> Synthesizes your schedule, pending tasks, and hardware health into an executive report.

### Deep Research:
- *"Search the web for top AI agent architecture trends in 2026."* -> Conducts live web research and provides source links.

---

## 3. Emergency Kill Switch

In the top right header, click **KILL SWITCH** to immediately halt all running autonomous workflows and background agent tasks. A confirmation dialog prevents accidental triggers.
